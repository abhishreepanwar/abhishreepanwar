## 🚀 Projects I'm Proud Of

### [IDEACT](https://github.com/abhishreepanwar/IDEACT)
AI-powered hackathon ideation platform. Analyzes problem statements, maps them to UN Sustainable Development Goals using TF-IDF + Logistic Regression, and generates project ideas with execution roadmaps. Trained on 510 India-focused problem statements.  
`Python` `FastAPI` `scikit-learn` `NLP` `HTML/JS`

### [SkillSync](https://github.com/abhishreepanwar/SkillSync)
Resume and interview analysis platform with NLP-powered feedback, personalized learning paths, and progress analytics. Built with Flask and integrated with the Gemini API.  
`Python` `Flask` `NLP` `Gemini API`

### [Fake News Detection System](https://github.com/abhishreepanwar/Fake_News_Detection_System)
ML classifier that detects misinformation in news articles using NLP preprocessing and classification models.  
`Python` `NLP` `scikit-learn`

### [Adaptive Learning Path Generator](https://github.com/abhishreepanwar/adaptive-learning-path-generator)
Generates personalized learning paths using clustering and classification — adapts to what a learner already knows.  
`Python` `ML` `Clustering`
